Etiqueta en píldora para clasificar contenido (categoría de servicio, estado) y, junto a ella, el eyebrow que antecede a un titular.

**Variantes.** `mk-tag` (borde `line-strong`), `mk-tag--soft` (fondo `brand-soft`, texto `brand-text`), `mk-tag--brand` (relleno `brand`, texto `on-brand`). El eyebrow suelto es `mk-eyebrow` en `brand-text`.

**Qué aporta quien lo usa.** Una o dos palabras, en el texto del DOM (el CSS las pasa a mayúsculas; estilo `label`).

**Hacer**

- Usa `mk-tag--brand` como máximo una vez por pantalla.
- Un eyebrow por sección, sobre el titular.

**No hacer**

- Etiquetas de promoción que el negocio no pueda sostener ("Más popular", "Recomendado") sin dato real detrás.
- Etiquetas clicables: para eso es un botón o enlace.
