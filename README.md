# Makma

Sitio web de Makma, casa de desarrollo de software. SvelteKit 3 + Svelte 5, tema oscuro con naranja `#FF4400` y blanco hueso.

```bash
npm install
cp .env.example .env   # opcional: define PUBLIC_WHATSAPP_NUMBER
npm run dev
```

Verificación: `npm run check && npm run lint && npm test && npm run build`.

Guía para trabajar en el proyecto (stack, sistema de diseño, reglas de contenido y pendientes): [`CLAUDE.md`](./CLAUDE.md). Diseño exportado: [`docs/diseno/`](./docs/diseno).
